## 二、第一千零一百五十章·思路方案

### 方案 A：以"法阵真相"为钩子（推荐，顺势回收 B 线）
**本章主线**：李星蹲在法阵边缘 → 通过李暗/直觉判断出法阵性质 → 发现它与林雀的联结 → 惊觉林雀有危险！

可写场景：
1. 李星仔细观察法阵纹路，与禁咒知识对照（禁咒法书/黑色魔法书的知识）
2. 李暗认出了法阵："这纹路……是记忆系的？"
3. 李星心口一悸——（呼应第五百六十七章"李星总有一种心悸的感觉"），直觉林雀出事
4. 校长在屋内结束试探，出门与李星汇合，两人交换信息：
   - 校长确认慕容灵"有问题"（洗脑/控制母亲）
   - 李星说出法阵发现
5. 两人赶回魔骑学院，发现林雀状态不对（记忆开始出现空白/恍惚）
6. **章末钩子**：林雀笑着说出某句"不记得"的话——李星心沉到谷底（"贪婪……开始了吗？"）

**本章收益**：把 A、B 两线拧成一股；林雀失忆的危机正式浮出水面；呼应伏笔"我不想忘记你"。

### 方案 B：以"慕容灵对峙"为钩子（推进 A 线正面冲突）
**本章主线**：校长在屋内与慕容灵母女周旋升级 → 试探 → 戳破 → 冲突爆发

可写场景：
1. 校长用"无欲"护身符（设定：抵抗精神魔法）暗中测试慕容灵反应
2. 慕容灵察觉被试探，演技与真身切换（内心戏：教团成员视角）
3. 叶萌珊（被控制）出现异常——母爱的挣扎闪现（洗脑的裂缝）
4. 校长与慕容灵言语交锋升级，李星在屋外布下后手
5. 慕容灵身份被识破的瞬间 → 她发动法阵 → **法阵的真正作用显现：把校长/李星困住/传送**（贪婪的"网"收口）
6. 章末：林雀独自在魔骑学院收到"慕容灵记忆恢复成功"的假象/陷阱信息……

**本章收益**：正面冲突刺激；法阵功能揭秘；把战火烧到林雀那边。

### 方案 C：以"林雀视角"为钩子（B 线正面展开）
**本章主线**：从林雀视角写记忆侵蚀的体验（代入感最强）

可写场景：
1. 清晨林雀醒来，发现自己"想不起昨天发生了什么"（日常小事开始遗忘）
2. 与韩希雪/崔清绮的对话中，林雀强装正常，但内心恐慌
3. 林雀独自检查自己的记忆（呼应她"能破解多层虚假记忆"的能力）——**发现记忆防御上黏着贪婪的魔法**
4. 林雀决定隐瞒（不想让李星担心），独自对抗——但越是使用记忆能力，侵蚀越深（恶性循环）
5. 李星回来，察觉到林雀的异常，两人之间第一次"善意的隐瞒"对峙
6. 章末：林雀晕倒/失忆瞬间——"李星！我不想……忘记……你！"

**本章收益**：最大情绪张力；林雀独立线展开；直接推进"忘记你"伏笔。

## 五、本章节奏建议（对话体参考）

话本对话体建议控制：
- **场景数**：2-3 个场景（如：慕容灵家外 → 返回学院 → 林雀房间）
- **对话量**：对半（对话 + 旁白/心理描写），避免整章纯对话
- **钩子**：章末留一个"转折/悬念句"（话本读者追更最吃这一套）
- **单章字数**：参考你最近 1500-2500 字，保持稳定
