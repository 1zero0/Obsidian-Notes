## 一、第一千零一百四十八章《异样感……》

### 🔴 错别字
| 位置 | 原文 | 建议 |
|---|---|---|
| 开头旁白 | 一直**侯**到半夜 | 一直**候**到半夜（"侯"为姓氏/爵位，"候"才是等待） |
| 贪婪魔法段 | 贪婪的魔法却是很细微**的**窜入了林雀的记忆 | 贪婪的魔法却极其细微**地**窜入了林雀的记忆（"的/地"混用） |
| 崔清绮台词 | #崔清绮 **斯**…… | #崔清绮 **嘶**……（拟声词） |
| 校长台词 | #校长 **斯**，这我还真没听说过 | #校长 **嘶**，这我还真没听说过 |

### 🟡 语病/冗长句
1. **"马上贴近林雀在林雀面前挥了挥手"** → "马上贴近林雀，**在她面前**挥了挥手"（避免"林雀"连用）
2. **林雀的大段台词**（"很奇怪，就好像没有失去记忆一样，但是她又没办法直接看到自己的记忆，直到刚才我尝试给她恢复记忆的时候，我发现她能看到了，不过之前也没有我也不知道是突然能看到还是刚能看到的就是了……"）
   → 建议拆短：
   > "很奇怪，就好像没有失去记忆一样。她之前根本看不到自己的记忆，直到刚才我试着给她恢复，她突然就能看到了。不过之前到底能不能看到，我也不清楚……唉，就是说不上的奇怪。"
3. **"第二天，林雀和李星罕见的没有早到，李星因为几乎一晚上没睡休息不过来，林雀因为记忆防御魔法被渗透记忆遭到了入侵，林雀没能早起"**
   → "第二天，林雀和李星罕见地没有早到——李星几乎一晚上没睡，缓不过来；林雀则因记忆防御被渗透、记忆遭到入侵，没能早起。"
4. **"李星迟疑了一瞬间，这个细节被亦园捕捉到了，李星也知道被捕捉到了，但他反而是眨了眨眼睛，亦园秒懂"**
   → "李星迟疑了一瞬，这个细节被亦园捕捉到；李星知道瞒不过她，反而眨了眨眼睛，亦园秒懂。"（去重复）
5. **"李星揉着自己的脖子，因为一个晚上没正经睡，只能这样睡，很是难受"**
   → "李星揉着脖子——一晚上没正经睡，只能将就着打盹，脖子酸得难受。"（补全"怎么睡"）

### 🟢 润色建议
- "她没什么表现，就是愣了一下，回来后到睡着都没有什么异常" → "回来后直到睡着都没什么异常"
- "林雀一把按住了李星" → 可加神态："林雀一把按住李星的手"

### 🔵 逻辑/一致性
- **# 与 \* 的混用**：本章公开对话用 `#角色名`，但李暗/李星内心对话用 `*角色名`（且前后带 `*` 包裹，在 Obsidian 里会被渲染成斜体）。若这是话本平台的角色标签设计（\* = 内心独白），建议在全章统一并坚持；若只是随手写的 markdown 星号，发布时会被吃掉，需改用平台内心戏格式。
- "李星，现在你能用饕餮了"的对照——本章"就要抽出饕餮"很好，前后一致。

## 二、第一千零一百四十九章《麻烦大了……》

### 🟡 语病/表意
1. **"她失忆了一天，没事吗？"**（李星）
   → 表意含糊。这里想说的是"慕容灵被教团搞失忆后放回来了，会不会有问题？"建议：
   > "是啊，我以为会被强迫加入教团。可她失忆了一天就被放回来了，没问题吗？"
2. **"慕容灵并没有表现出来，虽然这么说很假，但是她很有表演天赋"**
   → "虽然这么说很假"略显突兀，建议：
   > "慕容灵面上没有表现出任何异样——虽然这本身就假得很，但她确实很有表演天赋。"
3. **校长内心问题2**："这位母亲见我就有种恐惧感，一个正常家庭对于一个校长到来，应该是紧张，兴奋，激动，这明显很不对劲"
   → "紧张、兴奋、激动"三词并列稍显重复，可"应该是紧张或兴奋，而不是恐惧"

### 🟢 润色建议
- "母女俩的对话很简单，不能说有问题，但也不能说没问题" → "不能说有问题，但也不能说完全没问题"（更顺）
- "校长并没有继续这个话题，因为这是他们自己的选择" → 可加内心："（毕竟补贴这种事，他们自己取舍。）"

### 🔵 逻辑/一致性
1. **叶萌珊说"两个孩子"**："我这也还有个孩子嘛，两个孩子，住的稍微次一点"
   → 设定中慕容灵是叶萌珊的女儿，此处的"另一个孩子"是哪位？若是校长试探时的掩饰/谎言，建议加一句心理暗示（如：慕容灵在屋内听到差点露馅）；若设定有第二个孩子，请确认姓名，避免与后续矛盾。
2. **"前几天的那个学生"**（慕容灵内心："前几天那个学生……也没什么问题啊"）
   → 慕容灵知道"前几天有学生来过"？这条信息从哪来的？（是被洗脑残留，还是教团告知？）建议埋一句解释，否则读者会疑惑。
3. **148/149 章衔接**：148 章结尾校长说"先去那个女孩家看看"，149 章开头直接到"这户人家"——衔接自然，OK。但 149 章标题《麻烦大了……》与 148 章《异样感……》构成递进，很好。

## 三、两章通读后的整体建议

1. **"斯"→"嘶" 是高频错别字**，建议全文搜索替换（不止这两章）
2. **"的/地/得"混用** 较多（"很细微的窜入""计划地盲点"），发布前可统一检查
3. **长台词拆分**：林雀的大段台词（148章）和校长内心分析（149章）信息量大，但读者读长句容易累，建议切成 2-3 句
4. **内心独白格式统一**：`*` 包裹的内心戏在全平台是否统一渲染，建议发布前在话本预览确认
5. **节奏很好**：148 章"检查不出问题"的无力感 + 149 章"法阵出现"的压迫感，悬念递进到位，继续保持！
