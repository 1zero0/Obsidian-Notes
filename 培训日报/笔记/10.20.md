# 三个环境的差别

| 差异/环境 | 测试               | 预发布（封板以后）                  | 生产（外网）      |
| ----- | ---------------- | -------------------------- | ----------- |
| 配置不一样 | 杂乱，可随意修改（可用GM工具） | 正式配置，只有要上线的东西，不能随意修改（GM禁用） | 正式配置，不可随意修改 |
| 服务器   | 内部服务器            | 内部服务器（预发布服务器）              | 正式服         |
|       |                  |                            | 第三方支付接口     |

从开始到封板提审期间都是：测试环境，测试服（可用GM）（开发服务器可能有多个、测试服（可能有多个；可能有测试服有一些特殊的配置环境：可以测试支付的环境；更改服务器时间））；进度要是比较好的话，每天都会打包
从封板提审到上线（预发布服）：打出最后一个包就拿走提审；审核通过才能得到一个最终包/发布包（要上线的包）
启动器：用于从最终包进入到测试服里
## 测试流程：测试每天要做的：
10.1开始，开发会开发新需求出来，到10.10（第二周：完成测试准备），每天在TAPD搜集新需求，并将需求上传到需求文档，并在测试人哪儿写自己名字；开始对自己负责的需求进行分析评审，有问题找策划开发进行评审解决掉；整理成测试点/测试用例，并且对测试用例进行评审；整个版本的所有需求都需要完成以上的要求，在完成测试准的时候要全部完成
准备工作出了需求分析，设备，用例，环境，
